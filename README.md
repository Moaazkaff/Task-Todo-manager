# Todo Task Manager

A simple 3-tier Todo Task Manager built with **Flask**, **MySQL**, and plain **HTML/CSS**.

This project is designed primarily as a DevOps practice repo — a lightweight app to
containerize, orchestrate, and deploy using Docker Compose, Kubernetes, and CI/CD
pipelines (Jenkins).

## Tech Stack

- **Frontend:** HTML, CSS, vanilla JavaScript (fetch API)
- **Backend:** Python (Flask) REST API
- **Database:** MySQL

## Architecture

Three independent services:

```
frontend  →  backend (Flask API)  →  db (MySQL)
```
